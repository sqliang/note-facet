**打开一篇笔记，看清多维判断，沿着依据找到重点。**

在 Obsidian 中提供随当前 Markdown 更新的可视化阅读面板：先看概览，再选择风险、机会、对象或关系，最后核对依据并定位原文。Markdown 始终是原始数据来源，插件组织已有信息，不重新给笔记打分。

## 已确认方向与本轮默认决策

- 服务个人知识学习、技术笔记、阅读摘录与知识回顾。
- 已有摘要优先，缺少摘要时可按需触发 AI。
- 本轮排除状态指标；交互偏可视化，但必须能锁定关键信息。
- 默认单篇右侧面板，支持固定笔记；先交付不依赖 AI 的阅读闭环。
- 可视化帮助选关注点，详情解释，原文供核对；不以图表数量衡量价值。
- 首个验证版本面向桌面端；原文只读，配置与可重建缓存由插件管理。

后四项中的具体布局、范围和阶段划分为设计建议，不代表用户已经逐项验证。

## 当前证据与边界

[test-1.md](../test-files/test-1.md) 与 [test-2.md](../test-files/test-2.md) 是两篇同 schema 的富字段样本：YAML 分析字段丰富、正文较短，但两篇之间没有相互链接。尚不能验证真实跨笔记关系、普通长文泛化或产品收益。

已有字段的写入者和生成方式未知；“来自 YAML”不等于人工撰写或事实核实。样本里的产品、市场及风险判断仅作为展示输入，本轮没有核验其真实性。

评分量程、信息熵定义及完整枚举字典尚未提供，默认保留原值，不妨碍基础开发。文档中的布局、时间和成功率为验收目标；静态检查、API 查阅均不能替代 Obsidian 内的运行验证。
